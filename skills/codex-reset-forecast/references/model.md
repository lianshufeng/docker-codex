# 预测模型与放行规则

使用“离散时间生存基线 + 时间条件化经验贝叶斯信号校正”的两层模型。第一层使用带 L2 正则化的离散时间生存逻辑回归，以一小时为时间步长：

```text
logit(hazard_t) = β0
  + β1 × log(1 + hours_since_last_reset)
  + β2 × decayed_tibo_signal
  + β3 × recent_incident
  + β4 × recent_release_or_milestone
  + β5 × sin(utc_hour)
  + β6 × cos(utc_hour)
```

累计概率由 `1 - ∏(1 - hazard_t)` 计算。固定预测节点为 2、4、8、12、24、72 小时，不生成超过 72 小时的预测。

第二层把每条 Tibo 重置意图与之后的真实重置结果配对。精确落地时间记为精确事件；只有承诺窗口的记录按区间删失；观察期内未落地的记录按右删失。针对当前信号，模型按 `signal_level`、`intent_class` 和可信度计算相似权重，并以“当前信号已经持续多久仍未重置”为条件，排除早于当前等待时长已经落地的不可比样本。

每个预测节点以第一层累计概率作为 Beta 先验均值，固定先验强度为 10；可比样本的加权成功和失败更新后验。最终概率取后验均值，区间取 Beta 后验正态近似的 95% 区间。小样本会自动向生存基线收缩，避免少数强预告把当前弱信号概率不合理抬高。

## 参数与回测

- L2 λ 候选值：`0.01, 0.1, 1, 10, 100`。
- 信号衰减小时候选值：`12, 24, 48, 72`。
- 使用 expanding-window 时间序列回测，比较 4、24、72 小时 Brier Score。
- 完整模型不优于基础模型时，使用只含 `log_hours_since_last_reset` 的基础模型。

## 门禁

- 少于 10 次可信重置：阻断预测。
- 10—24 次可信重置：只运行基础模型。
- 至少 25 次可信重置、至少 10 条历史信号且至少 3 条未命中信号：允许回归层比较完整特征；无论完整回归是否放行，只要当前信号存在于意图—结果数据集，均执行贝叶斯小样本校正。
- 数据源、时间、第二来源、收敛或回测校验失败：阻断预测。
- AI 不得修改脚本输出的概率、模型类型、系数、贡献方向或门禁状态。

## 模型与 LLM 的职责边界

- 预测概率、累计效应、模型状态和回测指标只由脚本计算。
- LLM 必须为每个固定预测节点提供基于本次公开数据的证据解读、支持因素、反向因素、不确定性和证据引用。
- LLM 解读不进入回归特征，不得上调、下调、平滑或重新取整概率。
- 页面必须把“模型依据”和“LLM 证据解读”分区展示，使读者可以审计两者来源。

## 结论与置信等级

- 选择第一个累计概率达到 `0.5` 的预测节点作为主要范围；若 72 小时仍未达到 `0.5`，使用 72 小时节点并明确只陈述概率，不断言届时一定重置。
- 回归层完整特征通过回测、意图—结果样本充足且历史确认重置少于 50 次时使用 `medium`；达到 50 次时才允许 `high`。
- 当前回归层降级为基础特征或贝叶斯有效意图样本不足时固定使用 `low`；门禁阻断固定使用 `unavailable`，所有主要概率和时间写 `null`。
- 最可能窗口直接使用 `forecast.most_likely_windows` 第一名，禁止另行推断。
- `recent_tibo_posts[].text_zh` 只用于中文页面展示，禁止作为训练特征；模型只能使用英文原文对应的结构化 `signal_level`、事件标签和时间。
