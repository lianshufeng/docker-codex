# 预测模型与放行规则

使用“Tibo 信号延迟主模型 + 历史间隔弱先验 + 当地工作时段分配”的模型。历史间隔层使用带 L2 正则化的离散时间生存逻辑回归，以一小时为时间步长，但只提供无信号兜底和贝叶斯弱先验：

```text
logit(hazard_t) = β0
  + β1 × log(1 + hours_since_last_reset)
  + β2 × exp(-hours_since_last_reset / cooldown_hours)
  + β3 × decayed_tibo_signal
  + β4 × recent_incident
  + β5 × recent_release_or_milestone
  + β6 × sin(utc_hour)
  + β7 × cos(utc_hour)
```

累计概率由 `1 - ∏(1 - hazard_t)` 计算。固定预测节点为 2、4、8、12、24、72 小时，不生成超过 72 小时的预测。

主模型把每条 Tibo 重置意图与之后的真实重置结果配对，直接学习“信号发生时间 → 具体重置时间”的延迟。精确落地时间记为精确事件；只有承诺窗口的记录按区间删失；观察期内未落地的记录按右删失。模型按 `signal_level`、`intent_class`、可信度和当前信号年龄计算相似权重；明确承诺主导短时窗口，方向性信号主导 24—72 小时范围，弱提及只提供较低权重。

等级 `4` 表示已经完成重置，只能作为结果事件，禁止进入信号延迟层。最近相关动态为等级 `4` 且之后没有未兑现等级 `1—3` 信号时，信号增量固定为零；基础模型通过 `post_reset_cooldown = exp(-hours_since_last_reset / cooldown_hours)` 学习重置后的短期冷却。冷却小时只能从 `6、12、24` 中按历史间隔回测选择，系数由 L2 回归学习，禁止人工强压为零概率。

每个预测节点以历史间隔累计概率作为 Beta 弱先验均值，先验强度为 1；历史信号的加权成功、失败和删失结果更新后验。最终概率取后验均值，区间取 Beta 后验正态近似的 95% 区间。不得因为样本门槛不足而完全禁用已经多次命中的 Tibo 因子。

预测节点之间的概率增量按 `current.tibo_work_timezone` 转换为 Tibo 当地时间，再结合当地 08:00—19:00 工作时段先验和历史确认重置的当地小时核密度分配到具体小时。必须使用 IANA 时区自动处理夏令时；国籍不得直接作为模型特征。

## 参数与回测

- L2 λ 候选值：`0.01, 0.1, 1, 10, 100`。
- 信号衰减小时候选值：`12, 24, 48, 72`。
- 重置后冷却小时候选值：`6, 12, 24`。
- 使用以每条历史 Tibo 信号为预测起点的 expanding-window 回测，比较 4、24、72 小时 Brier Score。
- 每一折只能使用该信号之前的事件与信号；最新信号必须作为最终留出样本，不得进入训练。
- 同时在相同信号起点计算历史间隔基线；信号主模型的 24 小时 Brier 不优于基线时不得标记为回测通过。

## 门禁

- 少于 10 次可信重置：阻断预测。
- 10—24 次可信重置：只运行基础模型。
- 至少 3 个可评估的逐步信号回测折，且信号主模型的 24 小时 Brier 不高于相同折上的历史间隔基线，才允许标记为回测通过。
- 数据源、时间、第二来源、收敛或回测校验失败：阻断预测。
- AI 不得修改脚本输出的概率、模型类型、系数、贡献方向或门禁状态。

## 模型与 LLM 的职责边界

- 预测概率、累计效应、工作时段分配、模型状态和回测指标只由脚本计算。
- LLM 必须为每个固定预测节点提供基于本次公开数据的证据解读、支持因素、反向因素、不确定性和证据引用。
- LLM 解读不进入回归特征，不得上调、下调、平滑或重新取整概率。
- 页面必须把“模型依据”和“LLM 证据解读”分区展示，使读者可以审计两者来源。

## 结论与置信等级

- 选择第一个累计概率达到 `0.5` 的预测节点作为主要范围；若 72 小时仍未达到 `0.5`，使用 72 小时节点并明确只陈述概率，不断言届时一定重置。
- 回归层完整特征通过回测、意图—结果样本充足且历史确认重置少于 50 次时使用 `medium`；达到 50 次时才允许 `high`。
- 当前回归层降级为基础特征或贝叶斯有效意图样本不足时固定使用 `low`；门禁阻断固定使用 `unavailable`，所有主要概率和时间写 `null`。
- 最可能窗口直接使用 `forecast.most_likely_windows` 第一名，禁止另行推断。
- `recent_tibo_posts[].text_zh` 只用于中文页面展示，禁止作为训练特征；模型只能使用英文原文对应的结构化 `signal_level`、事件标签和时间。
