# 外观主题验收

日期：2026-11-12。

## 实现

- 登录页和用户菜单提供“自动 / 浅色 / 深色”，默认自动。按浏览器本地时间在 08:00 起使用浅色、20:00 起使用深色，不跟随操作系统设置。
- 自动模式在下个边界调度，并最多每分钟校正设备时间变化；恢复焦点、页面显示或后台恢复时立即重新判断。手动模式没有自动切换定时器。
- 同步头部脚本在页面首次绘制前设置主题、原生控件配色和浏览器主题色。React 订阅同一控制器，切换不重新挂载聊天组件。
- 偏好保存在当前浏览器 localStorage，同源标签页同步；保存值无效或清空时恢复自动。禁止存储时仍可在当前页面切换。偏好不按账号同步。
- 颜色通过 CSS 变量适配，深色保留原声明作为回退值；登录、消息、表格、代码高亮、图片、时间、文件和弹窗使用同一主题。

## 隔离环境

从根目录和 Web Compose 生成独立项目 `codex-theme-acceptance`，MQTT 18888、Web 31028，独立 home、workspace、临时目录、Broker 数据、前端构建卷和 Web 用户数据。只复用既有依赖卷和本机已有镜像，没有安装浏览器。

配置位于 Git 忽略的 `acceptance/.runtime/theme` 和 `web/test-results/theme-config.json`。使用执行端镜像预装 Playwright 与 Chromium headless shell。浏览器上下文分别使用东京和 UTC 时区，手机视口为 390 × 844。
